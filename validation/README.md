# Validation

This folder contains the reproducible validation and verification evidence for the external reduced-order CO₂ wellbore and HEM choke model.

The reservoir simulator is not validated here. OPM Flow is treated as an external simulator.

Main contents:

- `reference/` — frozen external reference data, including NIST WebBook CO₂ property points;
- `figures/` — generated validation and verification figures;
- `results/` — generated CSV tables used to produce the figures.

See the root `README.md` and `VALIDATION.md` for the main validation summary and scientific scope.
